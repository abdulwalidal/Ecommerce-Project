# E-Commerce

A full-stack e-commerce application built with Java and Spring Boot.

This project is being developed as a real-world e-commerce application, with the backend built using Spring Boot and the frontend planned as part of the application. The project focuses on building a structured and maintainable application while applying practical backend and web development concepts.

> **Status:** Under Development

## Overview

The application is designed to provide the core functionality of an e-commerce platform, including product management, categories, users, shopping carts, and orders.

The project is being developed incrementally, starting with the backend and database layer before moving towards the frontend and complete application integration.

## Tech Stack

### Backend

- Java
- Spring Boot
- Spring Data JPA
- Hibernate
- REST APIs
- Maven

### Database

- PostgreSQL

### Frontend

- Thymeleaf
- HTML
- CSS
- JavaScript

### Development Tools

- IntelliJ IDEA
- Postman
- Git & GitHub

## Features

The application will include functionality such as:

- Product management
- Product categories
- User management
- Product browsing
- Shopping cart
- Order management
- RESTful APIs
- Database persistence
- Server-side rendered pages
- Form handling and validation
- Exception handling

Additional features will be added as development continues.

## Project Structure

The project is being organized using a layered architecture to keep the application maintainable and easier to extend.

```text
src/
└── main/
    ├── java/
    │   └── ...
    └── resources/
        ├── templates/
        └── application.properties
````

## Development

The project is currently under active development. The backend and core functionality are being implemented first, followed by the remaining application features and frontend improvements.

The structure and implementation may change as the project evolves.

## Purpose

The main purpose of this project is to gain practical experience building a real-world application with Java and Spring Boot while working with REST APIs, relational databases, JPA, Hibernate, server-side rendering, and layered application architecture.
